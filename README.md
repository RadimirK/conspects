# Конспекты

Obsidian-хранилище с конспектами + сайт на [Quartz 5](https://quartz.jzhao.xyz),
который публикуется на GitHub Pages.

## Что где лежит

| Путь | Что это |
|---|---|
| `конспекты/` | Obsidian-хранилище. Здесь и только здесь пишутся заметки. |
| `site/` | Quartz: конфиг, тема, плагины. `site/content` — симлинк на `конспекты/`. |
| `site/plugins/tikzjax/` | Локальный плагин: рендерит блоки ` ```tikz ` в SVG на этапе сборки. |
| `site/quartz/static/tikzjax/` | Шрифты Computer Modern для TikZ-диаграмм. |
| `фотки1/`, `фотки2/`, `фотки3/` | Фотографии тетрадей. В git не попадают (см. `.gitignore`). |

## Как опубликовать изменения

Пишешь заметки в Obsidian как обычно, потом:

```bash
git add -A && git commit -m "конспекты: ..." && git push
```

GitHub Actions соберёт сайт и выложит его на Pages. Прогресс — во вкладке Actions.

## Локальный предпросмотр

Нужен npm (в системе его нет, ставится так):

```bash
sudo apt install npm
```

Дальше:

```bash
cd site && npm ci && npx quartz plugin install --from-config && npx quartz build --serve -c 1
```

Сайт откроется на http://localhost:8080.

## TikZ-диаграммы

Блоки ` ```tikz ` рендерятся при сборке через `node-tikzjax` — тот же TeX,
что и в плагине TikZJax для Obsidian, так что синтаксис совпадает
(`\begin{document} … \end{document}` обязательны). По умолчанию
подключены `amsmath`, `amssymb`, `amsfonts` — их можно поменять в
`site/quartz.config.yaml` в секции плагина `./plugins/tikzjax`.

Ограничения (такие же, как у плагина в Obsidian):

- **Кириллицы внутри диаграмм нет** — в этот TeX не встроены кириллические
  шрифты. Подпись вроде `node {делим на 10 отрезков}` уронит рендер; такую
  подпись нужно писать латиницей/формулой или выносить в текст под диаграммой.
  Если диаграмма не собралась, на сайте вместо неё будет её исходник.
- Доступны только пакеты, вшитые в сборку: `amsmath`, `amssymb`, `amsfonts`,
  `amstext`, `array`, `pgfplots`, `tikz-cd`, `tikz-3dplot`, `circuitikz`, `chemfig`.

Собирать нужно в один поток (`-c 1`): TeX-движок хранит глобальное состояние
и не переживает параллельных запусков.
