# II. Элементы теории множеств

← [[Элементы математической логики]] · [[Матанализ]] · далее: [[Отображения]]

> [!definition] Def
> $A$ — **множество** — совокупность объектов, объединённых какими-либо общими признаками (-ом).

$\varnothing$ — **пустое множество** — множество, в котором нет ни одного элемента.

- $a \in A$ — $a$ — элемент множества $A$
- $a \notin A$ — $a$ не принадлежит $A$

$M$ — **универсальное множество**, в котором содержатся все наши множества ($a \in M$).

## Операции над множествами

### Дополнение

$$\overline{A} = C_M A = \{x \mid x \in M \,\&\, x \notin A\}$$
— дополнение множества $A$ (всё, что лежит в $M$ вне $A$).

### Пересечение

$$A \cap B = \{x \mid x \in A \,\&\, x \in B\}$$

```tikz
  \end{scope}
  \draw (0,0) circle (1.2) node[left=0.6cm] {$A$};
  \draw (1.3,0) circle (1.2) node[right=0.6cm] {$B$};
\end{tikzpicture}
\end{document}
```

### Объединение

$$A \cup B = \{x \mid x \in A \lor x \in B\}$$

```tikz
\begin{document}

  \fill[blue!25] (0,0) circle (1.2);
  \fill[blue!25] (1.3,0) circle (1.2);
  \draw (0,0) circle (1.2) node[left=0.6cm] {$A$};
  \draw (1.3,0) circle (1.2) node[right=0.6cm] {$B$};
\end{tikzpicture}
\end{document}
```

### Подмножество, равенство

- $A \subset B$ — **подмножество** (включение нестрогое: $A = B$ допускается)
- $A \subsetneq B$ — **собственное** подмножество ($A \subset B$ и $A \neq B$)
- $A = B \iff A \subset B \,\&\, B \subset A$

> [!warning] При оцифровке
> Рядом с «$A \subset B$» стояла пометка «собственное подмножество» — она не согласуется со следующей строкой: при строгом включении $A \subset B \,\&\, B \subset A$ невозможно. Здесь и далее «$\subset$» — нестрогое включение.

### Разность

$$A \setminus B = \{x \mid x \in A \,\&\, x \notin B\}$$

$$A \,\triangle\, B = (A \setminus B) \cup (B \setminus A)$$

> [!example] Примеры
> $$\{\{1, 2\}, 3, 4\} \neq \{1, 2, 3, 4\} = \{1, 2, 3, 3, 4\}$$
> $$\{\varnothing\} \neq \varnothing$$

## Правила де Моргана (принцип двойственности)

$$\overline{A \cap B} = \overline{A} \cup \overline{B}$$
$$\overline{A \cup B} = \overline{A} \cap \overline{B}$$

**Доказательство:**
$$x \in \overline{A \cap B} \iff \neg(x \in A \,\&\, x \in B) \iff \neg(x \in A) \lor \neg(x \in B) \iff$$
$$\iff x \in \overline{A} \lor x \in \overline{B} \iff x \in \overline{A} \cup \overline{B}$$

Для произвольного семейства множеств:
$$\overline{\bigcap_k A_k} = \bigcup_k \overline{A_k}$$
$$\overline{\bigcup_k A_k} = \bigcap_k \overline{A_k}$$

## Декартово произведение множеств

> [!definition] Def
> $A, B$ — множества.
> $A \times B$ — множество упорядоченных пар из элементов $A$ и $B$:
> $$A \times B = \{(a, b) \mid a \in A,\ b \in B\}$$

- $A \times B \neq B \times A$ (при $A \neq B$), т.к. $(a, b) \neq (b, a)$
- $(A \times B) \times C \neq A \times B \times C$, т.к. элементы — $((a, b), c)$ и $(a, b, c)$ соответственно

> [!example] Пример: окружность × окружность = тор («бублик»)
> $$S^1 \times S^1 = T^2$$
> Каждой точке $a$ первой (большой) окружности сопоставляется целая копия второй (маленькой) окружности — «сечение» бублика в этой точке. Все такие пары $(a, b)$ вместе заметают поверхность тора.

```tikz
\begin{document}
\begin{tikzpicture}
  % тор
  \draw (0,0) ellipse (2.6 and 1.4);
  \draw (-1.2,0.1) .. controls (-0.5,-0.45) and (0.5,-0.45) .. (1.2,0.1);
  \draw (-0.9,-0.1) .. controls (-0.4,0.25) and (0.4,0.25) .. (0.9,-0.1);
  % большая окружность (первый множитель)
  \draw[blue, thick, dashed] (0,-0.05) ellipse (1.95 and 0.85);
  % малая окружность (второй множитель) — сечение в точке a
  \draw[red, thick] (1.95,-0.05) ellipse (0.33 and 0.55);
  \fill[blue] (1.95,-0.05) circle (0.05) node[right=2pt] {$a$};
  \node[blue] at (-1.2,-0.75) {$S^1$};
  \node[red] at (2.55,0.6) {$S^1$};
\end{tikzpicture}
\end{document}
```

## Упорядоченные множества

Множество называется **упорядоченным**, если между его элементами установлено отношение (отношение порядка), удовлетворяющее аксиомам 1°–3°.

«$\leq$» — «не превосходит»:

1. $a \leq a$ (рефлексивность)
2. $(a \leq b) \,\&\, (b \leq a) \Rightarrow a = b$ (антисимметричность)
3. $(a \leq b) \,\&\, (b \leq c) \Rightarrow a \leq c$ (транзитивность)

> [!note] Уточнение
> Аксиомы 1°–3° задают **частичный** порядок. Для **линейного** (полного) порядка нужно ещё требовать сравнимость: $\forall a, b$ выполнено $a \leq b$ или $b \leq a$. Порядок на $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}$ — линейный; упорядочение многоугольников по числу вершин из примера ниже — тоже, а, скажем, включение множеств «$\subset$» — только частичный.

> [!example] Пример
> Множество многоугольников:
> - «$\leq_1$» — по количеству вершин
> - «$\leq_2$» — по площади
>
> $\Rightarrow$ получаем 2 упорядоченных множества.
